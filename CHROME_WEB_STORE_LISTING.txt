PRIVACY SECTION
--------------------------------------------------------------------------------

SINGLE PURPOSE DESCRIPTION:
This extension detects anti-bot systems, CAPTCHAs, and browser fingerprinting technologies present on web pages. It analyzes cookies, scripts, DOM elements, and JavaScript variables to identify security protection systems, displaying results to help developers, researchers, and security professionals understand website security measures.

PERMISSION JUSTIFICATIONS:

storage justification:
Required to cache detection results and user settings (cache duration, fingerprinting toggle, API key). This reduces unnecessary re-scanning and improves performance by storing results for previously analyzed pages.

activeTab justification:
Required to access the current tab's content when the user clicks the extension icon. This permission grants temporary access only to the active tab and only in response to a user action (clicking the extension icon). It allows the extension to analyze the page content, DOM elements, and loaded scripts for protection detection without requiring broad host permissions.

scripting justification:
Required to inject content scripts into the active tab when the user clicks the extension icon. The content scripts collect page data (HTML content, script sources, DOM elements, window properties) needed to detect anti-bot systems and CAPTCHAs. Scripts are only injected on-demand when the user explicitly requests a scan.

cookies justification:
Essential for detecting anti-bot protection systems. Most security solutions (Cloudflare, Akamai, DataDome, PerimeterX, etc.) use HttpOnly cookies that are only accessible via the chrome.cookies API. Without this permission, the extension cannot detect cookie-based protections which are the primary detection method for anti-bot systems. Cookie access is limited to the active tab's URL when the user clicks the extension.
